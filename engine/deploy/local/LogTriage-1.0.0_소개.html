보안 원칙

  • 로그는 이 PC(또는 사내 서버) 밖으로 나가지 않습니다. 화면은 엄격한 CSP 로 외부 연결을 막습니다.
  • 룰팩은 Ed25519 서명만 받고, 처음 등록할 때 키 지문을 사람이 대조합니다.
  • 학습 룰의 정규식은 안전 검사(재앙적 역추적 차단)를 통과해야 하고, 사람 승인 전에는 판정에 쓰이지 않습니다.
  • 현장 실행 결과는 머리글만 받습니다(값 거절). 공용 비밀번호는 scrypt 검증값으로만 보관합니다.
