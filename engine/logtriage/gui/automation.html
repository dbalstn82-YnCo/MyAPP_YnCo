산출물 저장 설정
서버와 로컬에 함께 저장하는 방법 — ① 서버: 위 저장 경로 · ② 다른 서버/공유 폴더: 추가 사본 경로 · ③ 본사: 전사 연동(conf/hub.json) 시 자동 전송 · ④ 내 PC: [산출물 · 내려받기]의 자동 내려받기. Windows 설치형(LogTriage.exe)은 서버가 곧 이 PC이므로 저장 경로가 바로 PC 폴더입니다. 경로를 바꿔도 이미 만든 파일은 옮기지 않습니다.

백업 · 복원 안내
백업 ZIP 은 backups/backup-*.zip 에 .sha256 와 함께 저장됩니다(SQLite 무결성 검사 통과 시 성공). 암호화하지 않으며 설정·토큰을 포함할 수 있어 관리자만 내려받습니다.
복원은 프로그램/서비스를 종료한 뒤 — Linux: python -m logtriage.automation_admin verify --base /opt/logtriage --archive backups/backup-….zip → … restore … --offline-confirmed · Windows: LogTriage.exe --automation-admin verify --archive backups\backup-….zip
